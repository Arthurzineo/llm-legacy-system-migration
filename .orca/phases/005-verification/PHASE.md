# Part 2 — Independent Verification

## Purpose

Compare observable behavior; run regressions, static/dynamic security checks and review.

## Entry criteria

The Chief has verified the project root, current runtime roster, work ownership, required tools/skills and user permission for any side effects. An optional stage is skipped only after a recorded user decision.

## Exit criteria

Independent verification or explicit self-review limitation; critical risk accepted or remediated.

## Evidence and reporting

Record tasks, one diary per executing agent, explicit uncertainty, a reviewer decision and an auditable gate result. Do not mark this phase completed simply because a Markdown file exists.
