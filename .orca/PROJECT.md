## Objective

Create a reusable, language-agnostic ORCA workflow and modular skills for evidence-backed migration of unsupported legacy systems. Implementation can use one Chief or multiple agents depending on current runtime availability.

## Scope

Generic project entry, phase/task/diary/contract coordination, domain skill discovery and installation, staged static reverse engineering, optional dynamic characterization, interactive migration planning, controlled implementation, and independent verification mechanisms.

## Non-goals

No forced agent fleet, no permanent single vendor, no automatic creation of a GitHub repository, no unconditional Docker execution, no assumed connected memory server, no full code migration in the current branch.

## Authority and precedence

Current Chief instruction > active contract/task > phase > this project record > verified source and authoritative documents > execution summary > derived AI Memory/Graphify indexes. A task cannot override verified facts or explicit user authorization boundaries.
