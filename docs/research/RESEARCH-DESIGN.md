# Research Evaluation Design

Hypothesis: preserving verifiable source/runtime evidence through a structured ORCA workflow improves the rate of behavior-preserving legacy migration compared to a single-prompt rewrite.

Recommended controlled comparisons: (A) direct LLM migration; (B) static AST and documentation; (C) evidence-backed Graphify/AI Memory retrieval; (D) iteration with compiler/test feedback; (E) optional independent reviewers. Control model, temperature, source revision, test cases, token budgets and human interventions where possible. Do not confuse the number of agents with the contribution of deterministic tools. Report functional equivalence, critical regressions, engineer effort, dollar cost and execution time. Predeclare holdout tests and statistical analysis before evaluating models.
