# Start an ORCA Superpower

The following user-facing prompts can be used in any supported agent runtime. The user may speak Portuguese; the **project artifacts and skills remain in English**. An agent must read `AGENTS.md`, the selected superpower SKILL.md and the relevant project context before work.

## Superpower 0 — ORCA foundation

> Start ORCA for this project. Read `skills/superpowers/superpower-orca/SKILL.md`, discover available agents in this session, select Chief-only or delegated mode, inspect existing `.orca/` state and prepare a safe project entry. Do not fabricate agents, tasks or Graphify/AI Memory availability.

## Superpower 1 — Static discovery

> Start Part 1. Read `skills/superpowers/superpower-legacy-discovery/SKILL.md`, then route static inventory, decomposition, evidence-backed diagrams and G1 review through the actual ORCA tasks and contracts. Keep the legacy source read-only and mark unsupported tooling and unverified claims.

## Superpower 1.1 — Optional dynamic characterization

> Start Part 1.1. Read `skills/superpowers/superpower-legacy-characterization/SKILL.md`. First explain the feasibility, resources and security boundaries; ask me YES / NO / DEFER and record my decision. Do not run containers, execute legacy code or install tools without my approval.

## Superpower 2 — Planning, implementation and verification

> Start Part 2. Read `skills/superpowers/superpower-legacy-migration/SKILL.md`. Check G1 and the Part 1.1 decision, run the architecture and technology questionnaire, write a target migration plan, and get G2 approval before implementation. For subsequent slices use contracts, behavioral tests, equivalence evidence and explicit G3 cutover authorization.
